# 课程表提醒(麦麦插件)

> 🤖 **本项目由 AI 生成**(代码、文档与测试),经人工实测与真实麦麦环境验证。

导入教务系统导出的 `.ics` 课表,在上课**前 N 分钟**(默认 20)主动私聊提醒你。
文案不是插件写死的——它把事实交给**你自己的麦麦**,按宿主的人设来说。

## 特性

- **导入方式多**:`/课程解析` 引导发文件、直接发 `.ics`、放进本地目录、公网网址导入
  (网址课表默认每 6 小时自动检查更新,有变动才覆盖并通知)。支持 `RRULE` 重复、
  `EXDATE` 调休、`RECURRENCE-ID` 调课。
- **导入即订阅**:私聊里导入成功,当前会话就开始收提醒,不用再发订阅命令。
- **学习收纳(陪伴/辅助学习)**:自然语言记笔记——「记一下 欧拉公式 e^iπ+1=0」
  「这个是重点」「这个是公式」,按**正在上的课**自动归档;图片也能收。
  笔记按课分目录存成可直接阅读的文件,`/笔记` 查看、`/找 关键词` 检索、
  `/归到 课程名` 纠正归属。
- **截图里的公式自动认出来**:图片笔记除存原图外,还会送进视觉模型识别成
  LaTeX + 中文名称 + 知识点,落进公式库并打标签。**全自动,不需要你为识别做任何
  操作**——发图时自动认,Key 是后来才配的、或某次识别网络失败过,插件会在装载时
  把库里还没有公式的图片自动补识别一遍。**同一张图只识别一次**(图片 hash 缓存,
  不重复计费),**同一公式只存一条**(LaTeX 归一化后取指纹去重),没把握的标
  `#待确认` 而不是编个名字。识别在后台队列做,不阻塞聊天;没配 Key 就自动跳过,
  笔记照收。
- **提前量按会话独立**:同一节课,会话 A 提前 30 分钟、会话 B 提前 10 分钟,互不干扰。
- **默认只在私聊工作**:课表是个人日程,群聊里的命令、文件、注入、投递一律不响应。
  想让群聊也能用,把 `access.chat_scope` 改成 `"both"`。
- **自动识别法定节假日**:放假当天不提醒;**调休上班日照常提醒**;拿不到数据就照常
  提醒(宁可假期多提醒一次,也不漏掉上课日)。
- **自然语言问课**:直接问「明天有课吗」,麦麦按课表用自己的语气回答。
- **不丢提醒**:重启不重复提醒;机器人短暂离线错过的,只要课还没开始就补发。
- 改设置不用重启;支持访问白/黑名单。

## 快速开始

1. 安装插件(二选一):

   - 下载 [最新 Release](https://github.com/BUNNY-19C/maibot-class_schedule-plugin/releases/latest)
     里的 zip,解压到麦麦的插件目录;
   - 或把本仓库放进插件目录,目录名保持 `maibot_plugin_class_schedule`:

   ```
   MaiBot/plugins/maibot_plugin_class_schedule/
   ```

2. 重启麦麦。首次启动会自动安装依赖(`python-dateutil`)、生成 `config.toml`、
   建好课表目录。

3. 在**私聊**里发 `/课程解析`,然后把 `.ics` 文件发给机器人。
   (也可以跳过命令,直接把文件发给它。)

```
/课程解析          → 麦麦:请把 ics 文件发给我
(发 .ics 文件)     → 麦麦:已导入,解析出 N 条课程,本会话已自动订阅提醒
```

导入成功后**当前会话自动开始收上课提醒**,不用再发订阅命令(`file_import.auto_subscribe`
可关;`/课表订阅` 命令仍然保留,用于把其它会话加进来)。

`/课表状态` 随时能看运行状况,`/课表` / `/课表明日` / `/课表本周` 查课表。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/课表` / `/课表明日` / `/课表本周` | 查看今天 / 明天 / 今天起七天的课 |
| `/课程解析` | 引导导入:回你一句提示,然后等你发 ics 文件 |
| (把 .ics 文件发给机器人) | 直接导入课表 |
| `/课表导入 <网址>` | 从公网 http/https 网址导入 |
| `/课表重载` | 重新扫描课表目录 |
| `/课表订阅` / `/课表退订` | 当前会话开始 / 停止收提醒 |
| `/笔记 [课程名]` | 学习笔记:不带名字看概览,带名字看该课最近 10 条 |
| `/归到 课程名` | 把最近一条「未分类」笔记归到指定课程 |
| `/找 关键词` | 跨课程搜索学习笔记 |
| `/笔记库` | 笔记库状态:条数/状态分布/公式数,以及公式识别的累计结果与队列积压 |
| `/课表提前 [分钟]` | 查看或设置**本会话**的提前量,`重置` 回到配置默认 |
| `/课表假日` | 节假日数据状态与今日性质 |
| `/课表状态` | 运行状态、本会话可用标识、提醒会话列表 |

另外注册了 LLM 工具 `query_class_schedule`,所以「今天有什么课」这类问题麦麦也能答。

## 常用配置

配置在 WebUI 的插件配置页里改,或直接编辑插件目录下的 `config.toml`,**改完立即生效**。

```toml
[reminder]
remind_before_minutes = 20    # 默认提前多少分钟
check_interval_seconds = 60   # 检查间隔

[access]
chat_scope = "private"        # 默认只在私聊工作
tool_query_enabled = true     # LLM 能否查课表(名单管不到它)

[holiday]
skip_off_days = true          # 法定节假日不提醒
extra_dates = []              # 校历自定假日,如 ["2026-11-15", "05-20"]

[study]
cloud_enabled = true          # 云端能力总开关(关掉则图片只入库、不识别公式)
api_key = ""                  # 硅基流动 API Key;留空 = 不识别,笔记照收
vlm_model = "Qwen/Qwen3-VL-32B-Instruct"        # 公式识别模型
vlm_fallback_model = "Qwen/Qwen3-VL-8B-Instruct" # 识别失败时降级重试一次
```

完整字段(含提醒文案模板的占位符表)见 **[配置参考](docs/config.md)**。

## 需要注意

- **默认只走私聊**。群聊里发命令、发课表文件、问课都不会有反应——这是有意的默认值,
  改 `access.chat_scope` 可以放宽。
- **LLM 工具不受访问名单与适用范围限制**。麦麦调用工具时不传会话信息(已实测),
  所以如果机器人也在你不放心的群里,请把 `access.tool_query_enabled` 关掉。
- **网址导入只接受公网 http/https**(SSRF 防护,内网地址会被拒绝)。
  校园内网的教务系统请用聊天发文件或放进本地目录。
- **网址导入会自动刷新**:默认每 6 小时重新下载一次,**内容有变动才覆盖**
  并通知提醒会话(`source.url_refresh_hours` 可调,`0` 关闭);下载失败保留旧课表。
- **公式识别要联网,而且会把图片发给 API**:配了 `study.api_key` 并开着
  `cloud_enabled` 时,你发的图片笔记会被发送到你配置的 API 地址做识别
  (只走公网 https,内网地址一律拒绝)。不想让图片出本机就别配 Key——
  功能自动降级,笔记、原图、检索都不受影响。
- 其余限制(时区口径、全天事件、调课覆盖范围等)见
  [完整限制清单](docs/internals.md#完整限制清单)。
